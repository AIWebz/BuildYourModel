What can Solen build?
  • Text classifiers: sentiment, spam, topics
  • Number predictors and table classifiers, with custom layers if you want
  • Chatbots from question and answer pairs
  • Document Q&A and summarizers
  • Translators from sentence pairs
  • Mini GPT: a real transformer language model
  • Text generators: n-gram and neural character models
  • Image classifiers and image generators
  • Audio classifiers for .wav sounds
  • Clustering, anomaly detection, forecasting, recommenders
  • Game agents: reinforcement learning in a maze

Every model is small, trained from scratch on this server, and scored on held-out data where possible. Models at ChatGPT or video scale need GPU clusters, so Solen builds the closest small version and says so.
